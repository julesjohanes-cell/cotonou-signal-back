# Règles du dépôt Cotonou Signale (Prioritaires pour le code frontend)
Source : https://github.com/julesjohanes-cell/cotonou-signal-back/blob/main/frontend/AGENTS.md

Contrat : docs/openapi.yaml
- Équipe 1 : parcours de capture (catégorie, caméra, GPS, point sur la carte, envoi).
- Équipe 2 : carte des signalements, détail, suivi par code.
- Équipe 3 : espace mairie (connexion, liste, changement de statut, photo « après »).
- Mobile first, TypeScript strict.
- Caméra uniquement pour la capture (pas de sélection galerie).
- Coordonnées GeoJSON : [longitude, latitude].
- Affichage clair du tracking_code après envoi.
